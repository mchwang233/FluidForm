# 在飞书里聊得像个人

## 为什么

看了这台机器上的飞书对话（一个群聊、一个私聊），有六个问题：

1. **接着它的话说，它不理**：它反问"在广场哪一侧？"，对方回"西侧""你继续啊"，都被判成"不是问它的"，对方只好每次 @ 它。判断是不是在问它的模型，只看得到群里没 @ 它的那几句，看不到它自己刚说了什么。
2. **群里回答太长**：问 APEC 回了一篇带小标题的文章；认楼时"再补几点"列了一长串。
3. **只 @ 不说话时乱答**：没有新内容，它把之前四张图又全描述了一遍。
4. **说出了内部的东西**：
   - 图片的内部编号（`om_x100b…`）；
   - "（所选模型暂不可用，本次由「Codex CLI」回复。）"；
   - 反复解释"前面那个是 Codex，不是我"；
   - 网页上存下的消息带着"群里此前的消息（不是问你的，供参考）"这层包装。
5. **图片晚到一点，它说没看到图片**：问题和图片常常分开发，图片晚到了，对方只好再问一遍。
6. **回复慢**：选定的模型用不了时退到会员 Codex，一次回答 16–109 秒；DeepSeek 一般是 2–10 秒。

## 改动

1. **接话**（`api.automation_message`，`FOLLOW_UP_SECONDS`，状态里的 `answered`）：
   - 每段对话记下它最后一次回答的是谁、说了什么、是不是在反问对方。
   - 它刚反问过某人，5 分钟内这个人不 @ 它说的话，直接当作在回答它。
   - 其他没 @ 它的话，判断时也让判断的模型看到它刚才的回答。
2. **群里说短话**（`supervisor.chat_guide`）：
   - 群聊：每次两三句，不用小标题和长列表，有人要细说再展开，不重复说过的。
   - 私聊：像聊天那样，几句话。
3. **只 @ 不说话**：没有新的话、图片或要告诉它的事时，直接回"在呢，要我做什么？"，不调用模型。
4. **不说内部的东西**：
   - 给模型的消息里，图片只说"附 N 张图片"，不再写文件名（`_attached_note`）；
   - 换模型的提示只写进自动化日志；
   - 换了模型时告诉新模型：除非被问是谁，不提换模型的事；
   - 对话里存下的是大家说的原话：之前群里没 @ 它的几句加上这一句（`start_lead_chat(shown=)`），给模型的那层说明不存。
5. **等晚到的图片**（`capability_runner`，`PICTURE_WAIT_SECONDS`、`RECENT_PICTURE_SECONDS`）：
   - 文字里提到图片、照片、截图、这张……却没带图，而这个人两分钟内也没发过图时，最多等 8 秒。
   - 这期间他发来的图片和这个问题一起回答，那条只有图片的消息不再单独回。
6. **快的模型先上**（`supervisor.chat_order`、`_automation_chat_model`）：飞书这类自动化的对话，自动选和退的时候都先用 API 模型，会员 CLI 排在后面。网页对话不变。

## 测试

`test_capability_packages.py`：
- 回答它的反问不用 @（没有这次修改时测试失败，已验证）；
- 别人插话照样判断，判断时看得到它刚才的回答；
- 对话里存的是原话；
- 只 @ 时简短回复、不调用模型；
- 群聊规则要求说短话；自动化对话 API 模型在前；
- 晚到的图片和问题一起回答；两分钟内发过图时不等；
- 改了的地方，已有测试一并更新：图片不再按文件名说，换模型的提示只进日志，退的时候先用 API 模型。

## 风险

- **接话可能接错**：它反问完 5 分钟内，同一个人跟别人说的话，也会被当成在回答它。
- **提到图片但图片早就发过**：超过两分钟、又没带新图时，会多等 8 秒。
- **卡片权限**：飞书卡片还缺「创建与更新卡片」权限（`cardkit:card:write`），开通前看不到边写边刷新的回复。
