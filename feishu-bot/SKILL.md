# 飞书机器人

一个能力包（docs/design/capability-packages.md）。若水在后台运行它，它通过飞书的长连接收消息，所以不需要公网地址。

## 用法

1. 在飞书开放平台创建企业自建应用，打开「机器人」能力。
2. 「事件与回调」里选「使用长连接接收事件」，添加事件「接收消息 v2.0」（`im.message.receive_v1`）。
3. 权限里开通：读取用户发给机器人的单聊消息、获取群组中 @ 机器人的消息、以机器人身份发消息。
4. 发布应用版本。
5. 在若水的 平台工程师 → 能力 → 飞书机器人 里填 `FEISHU_APP_ID` 和 `FEISHU_APP_SECRET`，再启用。

## 说明

- 回：私聊的文字消息；群里 @ 了它的文字消息（@ 本身会去掉）。
- 不回：图片、文件等非文字消息；它启动前一分钟以前发的消息；同一条消息重复投递只回一次。
- 问题由这个飞书会话在若水里对应的那段对话回答，标题以「飞书机器人 ·」开头。
- 要动手的事在若水里排成任务，等主人确认；任务结束后，结果回复在原来那条消息下面。
- 回复太长会截断，并注明完整内容在若水里。
- 花费：若水按天限额（在能力卡片上改），超额后提示一次，当天不再回。

## 代码

- `bot.py`：收消息、问若水、回飞书。

## 检查

`python bot.py --check`：SDK 装好，哪些消息回的判断正确；不联网。

## 需要

- 密钥 `FEISHU_APP_ID`、`FEISHU_APP_SECRET`
- 访问 `*.feishu.cn`、`*.larksuite.com`
