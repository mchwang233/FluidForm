# 飞书机器人

一个能力包（docs/design/capability-packages.md）。FluidForm 在后台运行它，它通过飞书的长连接收消息，所以不需要公网地址。

飞书这一侧用飞书官方的 [lark-channel-sdk](https://pypi.org/project/lark-channel-sdk/)（Lark Technologies 出品，MIT）：长连接、消息解析、重复投递去重、回复、流式卡片、「敲键盘」表情、收发图片和文件、群成员、把「@名字」变成真正的 @，都是它做的。包里自己写的只有 FluidForm 这一侧：问 FluidForm、同一个人连发的几条合成一条、群里读不到名字的人叫「成员N」。

## 用法

1. 在飞书开放平台创建企业自建应用，打开「机器人」能力。
2. 「事件与回调」里选「使用长连接接收事件」，添加事件「接收消息 v2.0」（`im.message.receive_v1`）。
3. 权限里开通：读取用户发给机器人的单聊消息、获取群组中 @ 机器人的消息、以机器人身份发消息，「获取与上传图片或文件资源」（收图片和文件要用），「发送、删除消息表情回复」（处理时在消息上显示「敲键盘」表情），「创建与更新卡片」（用卡片回复、逐字显示），「查看群成员」（权限码 im:chat.members:read；开了「获取群组信息」im:chat:readonly 也行。用来读群成员名单：群里的人按名字称呼，回复里能 @ 到任何群成员；不开就只认得被 @ 过的人，其他人显示成"成员N"），以及「获取群组中所有消息」（群里没 @ 它的消息也能看到；这是敏感权限，可能要管理员审批，不开就只看 @ 它的）。
4. 发布应用版本。
5. 在 FluidForm 的 平台工程师 → 能力 → 飞书机器人 里填 `FEISHU_APP_ID` 和 `FEISHU_APP_SECRET`，再启用。

## 说明

- 回：私聊的文字、图片、文件和富文本（图文混排）；群里 @ 了它的文字和富文本（@ 本身会去掉；只 @ 不说话也回，就着刚才群里的话和图回答）。群里单发的图片没法 @ 它，要带图就用富文本。
- 群里没 @ 它的消息（文字、图片、文件）：交给 FluidForm，由最便宜的模型判断是不是在问它（比如叫它、问它能做的事、接着它上一句），是才回；不是就只记作群聊上下文（图片和文件也记下），之后回答时它知道大家刚才在聊什么、看得到刚才发的图，比如先发图、再 @ 它问「这是什么」。发言人按群里的名字显示（读不到名单时显示为「成员1」「成员2」）。@ 别人的消息不算叫它。
- 图片和文件会一起交给 FluidForm，聊天里看得到，排成的任务也带着；一条消息最多 10 个。
- 不回：表情包、语音、视频等；它启动前一分钟以前发的消息；同一条消息重复投递只回一次。
- 同一个人连着发的几条（间隔不到 0.8 秒）合成一条再问，回在最后一条下面；还没开始答时又来一条，就停下来两条一起答；已经在写或在用工具时，新的排在后面；话没说完时它只回一句引导，比如「嗯，你说」。怎么说话写在 `CHAT.md` 里，FluidForm 会交给回答的模型。
- 收到就在你那条消息上贴一个「敲键盘」表情，回复发出后撤掉。
- 命令（单独发一条，群里要 @ 它）：`/stop`（或「停止」「停下」）停下正在回答的；`/new`（或「新对话」）开新对话；`/status` 看状态。对话闲置 2 小时、每天 4 点也会开新的。
- 问题由这个飞书会话在 FluidForm 里对应的那段对话回答，标题以「飞书机器人 ·」开头。
- 要动手的事在 FluidForm 里排成任务；让它排的人回复「开始」就开工、「取消」就不做了（网页上也能确认）。任务结束后，结果回复在原来那条消息下面，做出的文件跟着发过来。
- 回复用卡片发，加粗、列表、代码块正常显示；API 模型回答时卡片里逐字出现，会员 CLI 答完一次出现。卡片发不出去（比如没开权限）就退回纯文本。
- 能发图片和文件：聊天里当场做出来的（比如一张图、一个表格）跟着回复发出，图片直接显示，其他是文件消息；需要「获取与上传图片或文件资源」权限。
- 回复里写的「@名字」「@成员N」「@所有人」会变成真正的 @（对方收到提醒）。机器人读群成员名单（SDK 缓存），把名单交给模型；「成员N」存在数据目录里，重启不丢。同名的两个人不猜，留成纯文字。
- 回复太长会截断，并注明完整内容在 FluidForm 里。
- 花费：FluidForm 只记账、不限额，能力卡片上能看到今天花了多少；飞书里不说金额。计价出错时照常回答，只是那次不记。

## 代码

- `CHAT.md`：在飞书私聊和群聊里怎么说话（简短、先结论、没说完先引导、群聊礼仪）。
- `bot.py`：用 lark-channel-sdk 收消息（图片和文件下载到数据目录的 `inbox/`，交给 FluidForm 后由它取走）、问 FluidForm、回飞书。

## 检查

`python bot.py --check`：SDK 装好，消息的文字和图片文件取得对、连发的话按人合并、回复里的 @ 对、FluidForm 的回答回到处理消息的那个循环；不联网。

## 需要

- FluidForm 的**聊天能力**（`requires: ["chat"]`）：怎么回答由它决定。没有启用「聊天」时，这个包不能启用。
- 密钥 `FEISHU_APP_ID`、`FEISHU_APP_SECRET`
- 访问 `*.feishu.cn`、`*.larksuite.com`
